Background Preview

Comparativo de 3 opções de background para o Hero. O atual usa vídeo de 2.9MB. Avalie as alternativas em CSS puro (zero peso) lado a lado.

Opção 1 — Atual (vídeo) 2.9 MB · webm

Prós: visual rico, movimento orgânico.
Contras: pesado (2.9MB), atrapalha LCP, autoplay bloqueado em iOS sem mute, consome bateria mobile.

Opção 2 — Gradiente suave ~0 KB · CSS puro

Prós: zero peso, movimento sutil elegante, mesma vibe premium.
Contras: menos detalhe que o vídeo, animação mais lenta.

Opção 3 — Tech grid + glow ~0 KB · CSS puro

Prós: visual "tech" mais marcante, grid alinhado ao branding.
Contras: mais carregado, pode competir com o H1.

Como decidir

  • • Olhe em 3G simulado (DevTools → Network → Slow 3G): qual carrega mais rápido?
  • • Olhe no celular: o vídeo gasta bateria? Os CSS não.
  • • Olhe o Lighthouse: rode em cada versão para ver o impacto no LCP.
  • • Considere que o vídeo atual tem 2.9MB — quase 1MB a mais que todo o bundle JS do site (~88KB gzipped).
